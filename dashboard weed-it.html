Add the data URL to activate this dashboard

Once the GitHub Action is set up and GitHub Pages is enabled on that repo, it will publish a data.json file at a URL like https://<username>.github.io/<repo>/data.json. Open this file, find dataUrl near the top of the <script> section, and replace YOUR_GITHUB_PAGES_DATA_URL with that link. Save and reload.

Checking for data… Corn, wheat & soybean: CBOT futures, continuous front-month contract, via Yahoo Finance, converted from US cents per bushel to US $ per metric tonne. Herbicide cost index: FRED PCU32533253, a monthly US producer price index for pesticide, fertilizer & other agricultural chemical manufacturing — a proxy, not a herbicide price. All four are fetched by a scheduled job once a day and published as one file, so this page just reads that file — no live API calls from the browser. Colour and the large figure reflect the change over the past year; the smaller figure is the latest move.
